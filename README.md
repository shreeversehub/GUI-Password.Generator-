# 🔐 GUI Password Generator

A simple and beginner-friendly Password Generator built using Python and Tkinter.

This application allows users to enter their name and instantly generate a password by combining the entered name with random symbols and digits.

## 🚀 Features

- Simple Graphical User Interface (GUI)
- Built with Python Tkinter
- Generates passwords instantly
- Random symbol generation
- Random digit generation
- Easy to use for beginners

## 🛠️ Technologies Used

- Python
- Tkinter
- Random Module

## 📸 How It Works

1. Enter your name.
2. Click the **Generate Password** button.
3. The application generates a password using:
   - Your name in lowercase
   - A random special character (@, #, $, _)
   - A random digit (0-9)

### Example

Input:
```
Lalitha
```

Output:
```
lalitha#7
```
